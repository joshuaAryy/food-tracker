# Phase 6.5 Design References

These files are visual references for the Phase 6.5 main app visual system
reset. They are reference material only; do not copy screens wholesale.

Stoic is the strongest mood and style reference for this phase. Cal AI is
mostly useful for onboarding structure and nutrition-specific flow ideas, not
the main visual style. Lifesum and Cronometer-style visuals should not be
copied. Green health references are mainly useful for wheel picker and
functionality ideas, not green CTA styling.

The simple mode icon is the default new-user brand mark. The complex mode icon
is for complex mode identity later.
